OpenAI 兼容协议推荐
Base URL
API Key在“API Key 管理”中创建的密钥
模型gemini-3.7-flash
认证方式Authorization: Bearer <API_KEY>

适用于 dsh、OpenAI SDK 及大多数支持自定义 OpenAI 地址的客户端。

Gemini 原生协议
Base URL
接口路径/v1beta/models/gemini-3.7-flash:generateContent
模型gemini-3.7-flash
认证方式x-goog-api-key: <API_KEY>

适用于 Google Gen AI SDK 或支持自定义 Gemini Base URL 的客户端。

Anthropic 兼容协议
Base URL
接口路径/v1/messages
模型gemini-3.7-flash
认证方式x-api-key: <API_KEY>

适用于 Anthropic SDK 及支持自定义 Anthropic 地址的客户端。

连接不上？确认 Asteria 正在运行、账号状态可用，地址与 API Key 没有多余空格。外部设备访问时还需放行端口并做好网络访问控制。
